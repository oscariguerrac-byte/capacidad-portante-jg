# Capacidad Portante J.G

Aplicación web instalable (PWA) para estimar la capacidad portante de cimentaciones superficiales con la ecuación general de capacidad portante — métodos de Terzaghi (1943), Meyerhof (1963) y Hansen (1970) — y factores de seguridad de la NSR-10, Título H.

Genera una memoria de cálculo imprimible en formato J.G Laboratorio de Suelos, Concretos y Pavimentos.

**Uso en el celular:** abrir la página publicada en Chrome (Android) o Safari (iPhone) → menú → *Instalar aplicación* / *Agregar a pantalla de inicio*. Funciona sin conexión; los datos se guardan solo en el dispositivo.

Prueba local: `powershell -ExecutionPolicy Bypass -File servidor.ps1` → http://localhost:8765
